Getting Started

This API allows users to manage freight shipment loads including loading points, unloading points, truck allocations, and shipment details.

Prerequisites

You need the following installed before running the application:

  • Python 3.8 or higher
  • SQLite

Installation

Follow these steps to install and set up the application:

  1. Clone the repository: 
    
git clone https://github.com/jv0019/task_manager_api.git
  2. Navigate to the project directory: 
    
cd task_manager_api
  3. Install the required Python packages: 
    
pip install -r requirements.txt

Running the Application

Run the Flask development server using:


python -m flask run

The application will run at:

http://127.0.0.1:5000

API Endpoints

Create Load

Endpoint: /load

Method: POST

Description: Creates a new freight load.

Example Request:


{
"loading_point": "Mumbai",
"unloading_point": "Pune",
"product_type": "Cement",
"truck_type": "Heavy",
"no_of_trucks": 3,
"weight": 500.0,
"shipper_id": "abc123",
"date": "2026-03-06"
}

Retrieve Loads

Endpoint: /load

Method: GET

Description: Retrieves all loads.

Retrieve Single Load

Endpoint: /load/<load_id>

Method: GET

Description: Retrieves a specific load using its ID.

Update Load

Endpoint: /load/<load_id>

Method: PUT

Description: Updates an existing load.

Delete Load

Endpoint: /load/<load_id>

Method: DELETE

Description: Deletes a load.

Database

Database Configuration

The application uses SQLite as the database for storing freight load records.

Database Models

The application currently includes the following model:

  • Load – Stores freight shipment data such as loading point, unloading point, product type, truck type, weight, and shipper ID.

Schemas

The API uses Marshmallow schemas to validate incoming JSON requests and serialize database objects.

Error Handling

The API returns appropriate HTTP status codes and JSON error messages when requests fail or invalid data is provided.

Testing

You can test the API using tools such as Postman by sending requests to the endpoints listed above.
